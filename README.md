# Nisha's 2D Game Engine
This is my custom 2D Game Engine project.
Developed by Nisha Batool
Based on open-source olcPixelGameEngine for learning purpose.
I have customized it and built my own mini-games on it.

Owner: Nisha Batool

## Play Star Catcher

Play the game in your browser: [Star Catcher](https://nisha-batool.github.io/pixel-game-framwork/).

Use the arrow keys or **A** and **D** to move; on a phone, use the on-screen
arrow buttons. Catch the golden stars and avoid the red bombs. You have three
lives, and the game gets faster as your score increases.

## Mini-game: Star Catcher

Catch the falling yellow stars and avoid the red bombs. You have three lives;
the game gets faster as your score increases.

- Move left and right with the arrow keys or **A** and **D**.
- Press **Enter** after game over to play again.
- Game source: `star_catcher.cpp`
- To play on Windows, double-click `Play Star Catcher.bat`.

Build and run `star_catcher.cpp` as a standalone olcPixelGameEngine application
using a C++17 compiler and the libraries required by olcPixelGameEngine on your
platform. Do not compile it together with `olcExampleProgram.cpp`; each file
defines its own `main()` and engine implementation.
